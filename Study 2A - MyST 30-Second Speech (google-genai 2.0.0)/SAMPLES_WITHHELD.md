# Sample transcripts withheld

This folder previously held a small set of example MyST transcript excerpts for
illustration. The MyST corpus is distributed by the Linguistic Data Consortium
under LDC2021S05, and its license does not permit redistribution of corpus
content, so those excerpts are not included in this public repository. The
corpus is available from the LDC at https://catalog.ldc.upenn.edu/LDC2021S05.
The stimulus construction script in `Code/` rebuilds every stimulus and
transcript file from a licensed copy of the corpus.
